# Problem-solving illustrations

These four original, repository-owned SVG diagrams support the problem-solving
chapter without depending on remote images, hotlinks, or third-party artwork.
They use the existing EduGround visual language: pastel surfaces, dark navy
outlines, geometric symbols, and green, violet, amber, and coral accents.

| File | Intended lesson placement |
| --- | --- |
| `decomposition-roadmap.svg` | Chapter introduction and the lesson on decomposing a specification into smaller verifiable steps |
| `dynamic-programming-table.svg` | Dynamic-programming lesson near the explanation of state, recurrence, memoization, and tabulation |
| `knapsack-choice.svg` | 0/1 knapsack lesson before the recurrence and table walkthrough |
| `problem-pattern-map.svg` | Famous-problems overview and the pattern-recognition recap |

Each asset has a fixed `viewBox`, scales responsively, and includes a concise
SVG `title` and `desc` for assistive technology. No explanatory prose is
embedded in the artwork, so the surrounding lesson remains the source of truth
and the diagrams remain legible at smaller sizes.

The assets were created specifically for this repository. They inherit the
repository's license when one is selected.
